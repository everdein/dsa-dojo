# Tries

## What Is a Trie?

A trie is a tree-like structure used to store strings by character.

## Why Tries Matter

Tries are efficient for autocomplete, prefix searching, and dictionary lookups.

## Example

```javascript
const trie = new Map();
```

## Practice Exercises

- Insert words
- Search prefixes
- Count words with a given prefix

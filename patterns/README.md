# Problem-Solving Patterns

## What Are Patterns?

Patterns are reusable strategies for solving groups of similar problems.

## Why They Matter

Recognizing a pattern often leads to a faster and clearer solution.

## Common Patterns

- Two pointers
- Sliding window
- Prefix sums
- Fast and slow pointers
- Intervals
- Binary search
- BFS
- DFS
